# 8/13

## テーブルに列を追加

```sql
ALTER TABLE テーブル名 ADD COLUMN 列名 データ型;

```

例: Workerテーブルにdepartmentを追加

```sql
ALTER TABLE Worker ADD COLUMN department VARCHAR(30);
```

## char型とvarchar型

- char型
  - 固定長
  - 指定した長さ以下の場合は空白が加えられる
- varchar型
  - 可変長
  - 指定した長さ以下でも空白はつかない
- 長さを超えた場合
  - strictモードが有効な場合はエラーが発生する
  - strictモードが無効な場合は切り捨てられる

## 単語境界

`\b`は単語の境界(先頭・末尾・空白・カンマ)を表す。

`\B `は逆に単語境界でない位置を表す。
