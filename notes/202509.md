## CROSS JOINとは

- 2つのテーブルのすべてのレコードを組み合わせる
- 結果の行数は「片方の行数 × もう片方の行数」となる

```
employees
+------+--------+
| ID   | Name   |
+------+--------+
|    1 | 鈴木   |
|    2 | 佐藤   |
|    3 | 田中   |
+------+--------+

projects
+-----------+
| Project   |
+-----------+
| A計画     |
| B計画     |
| C計画     |
+-----------+

SELECT * FROM employees
CROSS JOIN projects;
/* 結果
+------+------+---------+
| ID   | Name | Project |
+------+------+---------+
|    1 | 鈴木 | A計画   |
|    2 | 佐藤 | A計画   |
|    3 | 田中 | A計画   |
|    1 | 鈴木 | B計画   |
|    2 | 佐藤 | B計画   |
|    3 | 田中 | B計画   |
|    1 | 鈴木 | C計画   |
|    2 | 佐藤 | C計画   |
|    3 | 田中 | C計画   |
+------+------+---------+
*/


```

## 交差テーブル(中間テーブル)とは

- 多対多の関係を1対多の関係に分解するために必要
- 多対多のテーブルがある時にそれぞれを参照する外部キーで作成するテーブル

## 外部キーとは

- 別のテーブルのカラムを参照するために使われるキー
- データの整合性と一貫性を確保できる
